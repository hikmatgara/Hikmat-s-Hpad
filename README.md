# Stardance: 3-Key Productivity Hackpad

A minimal, elegant macro pad designed for power users who need quick access to essential browser and system shortcuts without cluttering their desk.

## Overview

Stardance is a compact, three-key mechanical keyboard pad built around the Seeeduino XIAO microcontroller. It's precision-engineered with a custom PCB and 3D-printed case, combining form and function for productive workflows.

## Key Features

- **3 Programmable Keys** with Cherry MX mechanical switches
- **USB HID Keyboard** - works on any OS (Windows, Mac, Linux)
- **Compact Design** - minimal footprint, maximum productivity
- **Custom Hardware** - hand-designed PCB and case
- **Easy to Modify** - open-source firmware with Arduino IDE support
- **High-Speed Controller** - Seeeduino XIAO with SAMD21 processor

## Default Shortcuts

| Key | Shortcut | Function |
|-----|----------|----------|
| Key 1 | Ctrl+Shift+S | Screenshot |
| Key 2 | Ctrl+Shift+N | New Window/Incognito |
| Key 3 | Ctrl+Shift+T | Reopen Closed Tab |

## Technical Specs

- **Microcontroller:** Seeeduino XIAO (SAMD21)
- **Switches:** 3x Cherry MX mechanical switches
- **Connectivity:** USB-C
- **Firmware:** Arduino-based, fully customizable
- **Case:** 3D-printed custom design
- **Power:** USB-powered, no battery required

## What's Included

- `stardance_firmware.ino` - Arduino firmware (ready to upload)
- `Steam Hpad.kicad_sch` - KiCad schematic
- `Steam Hpad.kicad_pcb` - KiCad PCB design
- `stardance_case/` - 3D model files for enclosure

## Getting Started

1. **Upload Firmware** - Load `stardance_firmware.ino` to XIAO via Arduino IDE
2. **Customize Shortcuts** - Edit the firmware to your preferred key combinations
3. **Print/Assemble** - Use the case files and PCB design to build your own
4. **Enjoy** - Start boosting your productivity!
